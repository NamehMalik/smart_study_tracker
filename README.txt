SMART STUDY PLANNER & PERFORMANCE TRACKER
Bennett University | Course 2026CSAE100

FILES
- smart_study_planner.py : complete menu-driven Python application
- study_data.json       : editable sample tasks / persistent local data

RUN
1. Install Python 3.9 or later.
2. Keep both files in the same folder.
3. Open a terminal in that folder.
4. Run: python smart_study_planner.py

FEATURES
Add and validate tasks; view task priorities; generate a priority-based
schedule; update progress; calculate a performance summary; save/load JSON.

NOTE
The included records are illustrative demonstration data, not actual
student performance records. The application uses the computer's current
date when calculating deadline urgency.
